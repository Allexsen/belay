# The built-in list: places where a change is rarely the task itself, and
# either runs code nobody asked to run, holds a credential, or changes what
# later automation does. A change to a match leads the receipt's one line.
#
# label <TAB> pattern. Patterns are .belay-donttouch's (README): `*` is any
# run within a name, `**` any run across names, both matching names that
# start with a dot; a pattern with no slash matches at any depth; a match
# on a directory covers everything below it. `.git/hooks/*.sample` is
# never flagged (belay-receipt.awk).
